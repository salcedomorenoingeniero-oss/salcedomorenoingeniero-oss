## Enfoque

Construyo **ontologías operativas** (wiki + SQLite + descargas de datos abiertos) y las conecto a asistentes de IA para:

1. **Auditoría ciudadana municipal** — SECOP II, CUIPO, SisPT, BPIN/SGR, señales de riesgo contractual.
2. **Finca cafetera de especialidad** — trazabilidad lote → recolección → beneficio → venta.
3. **Plantillas de conocimiento clínico familiar** — esquema y códigos estándar **sin publicar datos de pacientes**.
